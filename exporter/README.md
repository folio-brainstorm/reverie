# @reveriejs/exporter

World-region image export and PNG, JPEG, and WebP encoding for Rêverie.

```bash
pnpm add @reveriejs/core @reveriejs/exporter
```

The `@reveriejs/web` facade provides `reverie.download()` for browser applications. Import `ExportRenderer` from this package when you need direct control over world-region export.

See the [repository README](https://github.com/folio-brainstorm/reverie#readme) for the package map.
