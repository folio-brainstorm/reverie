# @reverie/core

Platform-independent World, Raster, Brush, Stroke, Camera, document, history, and rendering contracts for Rêverie.

```bash
pnpm add @reverie/core
```

Use `@reverie/web` for a ready-to-use browser canvas. Advanced integrations can import `RenderingCore` and its public contracts from `@reverie/core/rendering`. The `@reverie/core/rendering/internal` subpath is reserved for Rêverie packages and is not a user entry point.

See the [repository README](https://github.com/folio-brainstorm/reverie#readme) for a browser quick start.
